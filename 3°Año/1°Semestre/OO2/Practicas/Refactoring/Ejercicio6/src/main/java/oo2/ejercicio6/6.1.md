# Bad Smells identificados:

1. Falta de encapsulamiento, variables publicas (Encapsulated field)
2. Varibles y conceptos repetidos (Duplicated code)

Solucion:

1. Encapsulamiento: Pasar atributos a pivate o protected 
2. Codigo duplicado:
    - Variables: 
        * Extraer en una superclase las variables repetidas Pull up field:
        Como cantidadHijos y horasTrabajadas no se presentan en todas las clases, quedaran en subclases
    - Metodos:
        * Sueldo(): la estructura basica del metodo se repite basico + adicionales - retenciones, ademas 
        retenciones es exactamente igual en las 3 clases. Entonces aplicamos extract method para desglosarlo y 
        luego pull up method para subirlo a la superclase.
