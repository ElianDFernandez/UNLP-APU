1996 - 2000: Java, Javascript, XML
- Características: Java es un lenguaje de programación orientado a objetos que se ejecuta en una máquina virtual, lo que permite la portabilidad entre plataformas, Javascript es un lenguaje de scripting utilizado principalmente para el desarrollo web, y XML es un lenguaje de marcado utilizado para almacenar y transportar datos.

# Lenguajes - ADA

## Ejercicio 5:
Describa las características más relevantes de Ada, referida a:
● Tipos de datos
● Tipos abstractos de datos – paquetes
● Estructuras de datos
● Manejo de excepciones
● Manejo de concurrencia

- Tipos de datos: Ada soporta una amplia variedad de tipos de datos, incluyendo tipos escalares (enteros, reales, booleanos), tipos compuestos (arrays, registros), tipos de acceso (punteros) y tipos derivados. Además, Ada permite la definición de tipos personalizados a través de la declaración de nuevos tipos.
- Tipos abstractos de datos – paquetes: Ada utiliza paquetes para definir tipos abstractos de datos (TAD). Un paquete es una unidad de encapsulación que contiene la definición de un TAD, incluyendo su interfaz (especificación) y su implementación (cuerpo). Esto permite a los programadores ocultar los detalles de implementación y proporcionar una interfaz clara para interactuar con el TAD.
- Estructuras de datos: Ada proporciona estructuras de datos como arrays, registros y listas enlazadas. Los arrays pueden ser de tamaño fijo o dinámico, y los registros permiten agrupar diferentes tipos de datos bajo un mismo nombre. Además, Ada permite la creación de estructuras de datos personalizadas a través de la definición de nuevos tipos.
- Manejo de excepciones: Ada tiene un robusto sistema de manejo de excepciones que permite a los programadores manejar errores de manera estructurada. Las excepciones pueden ser definidas por el usuario o predefinidas por el lenguaje, y se pueden manejar utilizando bloques `begin...exception...end`. Esto permite a los programadores capturar y responder a errores de manera efectiva, mejorando la robustez del programa.
- Manejo de concurrencia: Ada tiene un modelo de concurrencia incorporado que permite a los programadores escribir programas concurrentes de manera sencilla. Ada utiliza tareas para representar unidades de ejecución concurrente, y proporciona mecanismos de sincronización como semáforos, monitores y rendezvous para coordinar la interacción entre tareas. Esto facilita la creación de programas que pueden aprovechar múltiples procesadores y manejar múltiples tareas simultáneamente.


# Lenguajes - JAVA

## Ejercicio 6:
Diga para qué fue, básicamente, creado Java.¿Qué cambios le introdujo a la Web?
¿Java es un lenguaje dependiente de la plataforma en dónde se ejecuta? ¿Por qué?

Java fue creado por James Gosling y su equipo en Sun Microsystems a principios de los años 90. El objetivo principal de Java era crear un lenguaje de programación que fuera independiente de la plataforma, lo que permitiría a los desarrolladores escribir código una vez y ejecutarlo en cualquier lugar sin necesidad de modificaciones. Esto se logró a través de la creación de la máquina virtual Java (JVM), que interpreta el código bytecode generado por el compilador Java.

Java introdujo cambios significativos a la Web al permitir el desarrollo de aplicaciones web interactivas y dinámicas. Con la introducción de Java applets, los desarrolladores pudieron crear aplicaciones que se ejecutaban dentro de los navegadores web, lo que permitió una experiencia de usuario más rica y atractiva. Además, Java se convirtió en un lenguaje popular para el desarrollo de aplicaciones empresariales y móviles, lo que contribuyó a su adopción generalizada en la industria.

Java no es un lenguaje dependiente de la plataforma en donde se ejecuta, ya que su diseño se basa en la idea de "write once, run anywhere". Esto significa que el código Java puede ser compilado en bytecode, que es un formato intermedio que puede ser ejecutado por la JVM en cualquier plataforma que tenga una implementación de la JVM. Esto permite a los desarrolladores escribir código Java sin preocuparse por las diferencias entre las plataformas, lo que facilita la portabilidad y la compatibilidad del código.

## Ejercicio 7:
¿Sobre qué lenguajes está basado?

Java está basado en varios lenguajes de programación, pero principalmente se inspira en C y C++. Java fue diseñado para ser un lenguaje de programación de propósito general que combina la simplicidad y la facilidad de uso de C con las características avanzadas de C++. Sin embargo, Java elimina algunas de las características más complejas y propensas a errores de C++, como la manipulación directa de memoria y los punteros, lo que contribuye a su seguridad y estabilidad. Además, Java también incorpora características de otros lenguajes como Smalltalk (programación orientada a objetos) y Ada (manejo de excepciones), lo que le permite ofrecer una amplia gama de funcionalidades para los desarrolladores.

## Ejercicio 8:
¿Qué son los applets? ¿Qué son los servlets?

Los applets son pequeñas aplicaciones Java que se ejecutan dentro de un navegador web. Fueron diseñados para proporcionar una experiencia interactiva y dinámica en la web, permitiendo a los desarrolladores crear contenido multimedia, juegos, gráficos y otras aplicaciones que se ejecutan directamente en el navegador del usuario. Sin embargo, debido a problemas de seguridad y la evolución de las tecnologías web, los applets han caído en desuso y ya no son ampliamente utilizados.

Los servlets, por otro lado, son componentes de servidor escritos en Java que se ejecutan en un servidor web. Los servlets se utilizan para manejar solicitudes HTTP y generar respuestas dinámicas, lo que los hace ideales para el desarrollo de aplicaciones web. A diferencia de los applets, los servlets se ejecutan en el servidor y no requieren que el usuario tenga Java instalado en su máquina. Los servlets son una parte fundamental de la plataforma Java EE (Enterprise Edition) y se utilizan ampliamente en el desarrollo de aplicaciones empresariales y servicios web.

# Lenguajes - C

## Ejercicio 9:
¿Cómo es la estructura de un programa escrito en C? ¿Existe anidamiento de
funciones?

La estructura de un programa escrito en C generalmente consta de las siguientes partes:
1. Directivas de preprocesador: Estas son instrucciones que se procesan antes de la compilación y suelen incluir la inclusión de bibliotecas estándar o personalizadas, así como la definición de macros. Por ejemplo: `#include <stdio.h>`.
2. Declaraciones de funciones: Aquí se declaran las funciones que se utilizarán en el programa, especificando su nombre, tipo de retorno y parámetros. Por ejemplo: `int suma(int a, int b);`.
3. Función principal: La función `main()` es el punto de entrada del programa, donde se ejecuta el código principal. Por ejemplo:
```c
int main() {
    // Código principal del programa
    return 0;
}
```
4. Definiciones de funciones: Aquí se definen las funciones declaradas anteriormente, proporcionando la implementación de su comportamiento. Por ejemplo:
```c
int suma(int a, int b) {
    return a + b;
}
```
En cuanto al anidamiento de funciones, C no permite la definición de funciones dentro de otras funciones. Todas las funciones deben ser definidas a nivel global, fuera de cualquier otra función. Sin embargo, es posible llamar a una función desde otra función, lo que permite la modularidad y la reutilización del código, pero no se puede anidar la definición de funciones dentro de otras funciones.

## Ejercicio 10:
Describa el manejo de expresiones que brinda el lenguaje.

C proporciona un manejo de expresiones bastante completo y flexible. Las expresiones en C pueden ser de varios tipos, incluyendo expresiones aritméticas, lógicas, de comparación, de asignación, entre otras. C permite el uso de operadores para combinar variables y valores en expresiones, y también permite la anidación de expresiones para crear cálculos más complejos. Por ejemplo, se pueden escribir expresiones como `x + y * z`, donde se aplican las reglas de precedencia de los operadores para determinar el orden de evaluación. Además, C permite el uso de paréntesis para controlar el orden de evaluación de las expresiones, lo que brinda a los programadores un gran control sobre cómo se evalúan las expresiones en su código. C también proporciona operadores de asignación compuestos, como `+=`, `-=`, `*=`, etc., que permiten realizar operaciones y asignaciones en una sola expresión. En resumen, el manejo de expresiones en C es robusto y permite a los programadores escribir código eficiente y expresivo para realizar una amplia variedad de operaciones y cálculos.
